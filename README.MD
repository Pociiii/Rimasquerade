# Rimasquerade

A **Vampire: The Masquerade-inspired mod for RimWorld**.

Rimasquerade brings vampires, blood, clans, disciplines, and the hidden world of the Kindred into RimWorld while aiming to remain as **vanilla-friendly as possible**.

The goal is not to turn RimWorld into a completely different game, but to integrate Vampire: The Masquerade concepts into RimWorld's existing systems.
